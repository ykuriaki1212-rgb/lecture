# タイトル：情報漏えいの原因と対応・対策

～「会社と自分」を守るための、一歩進んだワークスタイル～
本研修は、日夜第一線で活躍する営業社員の皆さまを対象とした、「明日から使える」情報セキュリティ基礎研修です。

セキュリティ対策は、決して誰かを縛ったり、ミスを責めたりするためにあるのではありません。大切なのは、**「自分自身と会社、そしてお客様を守る」**という視点です。

本講座では、知識の詰め込みではなく、日々の業務に潜む「意外な落とし穴」を自分事として捉え、前向きに対策を考えるきっかけを提供します。

📌 本研修の3つの特徴
「自分事」として考える体験型プログラム 一方的な講義は最小限に。ドラマ仕立ての動画視聴や、営業現場で起こりうるリアルなケーススタディを通じて、「自分ならどうするか」を仲間と一緒に考えます。

「責めない」学びの場 「なぜそうなったのか」の背景を大切にします。正解を押し付けるのではなく、グループワークで出た多様な意見を尊重し、納得感のある対策を導き出します。

「面倒くさい」に寄り添う具体策 「対策は大事だけど、正直手間がかかる……」という本音に寄り添います。実際のPC画面を用いた実演を交え、今日からすぐに実践できる「無理のない工夫」を伝授します。

✍️ 学習のステップ
【気づく】 ドラマ動画で学ぶ「悪意がなくても漏れる」現実

【考える】 グループワーク：営業現場の「ヒヤリハット」座談会

【知る】 完璧を目指さない！明日からできるスマートな対策実演

【持ち帰る】 現場で即活用できる「安心チェックリスト」の作成

「完璧」ではなく、「一歩ずつ」から。

セキュリティへの意識を変えることで、より自信を持って、より自由に仕事ができる環境を一緒に作っていきましょう。
